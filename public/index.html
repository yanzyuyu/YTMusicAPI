Developer Reference

YouTube Music & Spotify Player API

A lean, zero-dependency serverless music engine built with TypeScript. Provides full catalog search, high-bitrate audio streaming, studio-synchronized karaoke lyrics, and one-click Spotify playlist import without external SDK bloat or rate-limit lockouts.

Production Base URL Use https://<your-deployment>.vercel.app for cloud serverless functions or http://localhost:3000 during local testing. All endpoints support standard CORS and require zero API keys.

Architecture & Specifications

Built according to senior zero-dependency engineering standards. The system avoids third-party scraper bloat, utilizing native Node.js and lightweight InnerTube client wrappers for deterministic performance.

Zero-Dependency Core

Runs natively on Node.js 20+ runtime using standard fetch, AbortSignal, and streaming buffers. Zero heavy external binaries.

Multi-Source Synced Lyrics

Cascading synchronization engine querying LRCLIB and Kugou with millisecond precision, studio time tags, and custom timing offset calibration.

Direct CDN Audio Redirect

Resolves raw Google Video audio CDN streams with HTTP 302 redirection or direct URL extraction, enabling native hardware seek on mobile players.

GET /api/stream
Audio Stream & Seek

Resolves the best available audio stream from Google Video CDN. By default, responds with HTTP 302 Found redirecting directly to the high-bitrate audio buffer. Supports seeking via the start parameter.

Parameter Type Status Default Description
id string Required - YouTube video identifier
start number Optional 0 Initial playback seek position in seconds
redirect boolean Optional true Set false to return JSON payload with direct stream URL
Direct Stream Playback 
https://<your-domain>/api/stream?id=kPa7bsKwL-8&start=30

Deploying to Vercel via Vercel CLI

Step-by-step instructions for deploying this project into Vercel Serverless environment using the official CLI.

1
Install Vercel CLI
Install the CLI globally or run it via npx:
Terminal 
npm install -g vercel
2
Authenticate Your Account
Login to your Vercel account:
Terminal 
vercel login
3
Deploy Production Instance
From the repository root, execute the production deployment command:
Terminal 
vercel --prod --yes

Vercel compiles the TypeScript serverless functions in api/ automatically and serves public/ as static assets at the root URL.

Mobile APK & Client Integration Guide

How to wire this API to an Android APK (Java/Kotlin), Flutter, or React Native music app.

Standard Playback Lifecycle

  1. Catalog Search: Query /api/search?q={query} and display tracks in a RecyclerView or ListView.
  2. Audio Source: Pass https://<api>/api/stream?id={trackId} directly to ExoPlayer or just_audio. The endpoint automatically follows the 302 redirect to the audio stream.
  3. Seek Synchronization: When the user drags the timeline seek bar, call native player seek or query /api/stream?id={trackId}&start={seconds}.
  4. Karaoke Lyrics: Concurrently fetch /api/lyrics?title={title}&artist={artist}&duration={durationSeconds}. Loop over syncedLyrics and highlight the line where playerPosition >= item.time.
  5. Autoplay Next: When the track finishes, query /api/next?id={trackId} to continuously queue related tracks.

Code Snippets

Quick implementations across Flutter, JavaScript, and Python.

Flutter (Dart) 
import 'package:http/http.dart' as http;
import 'package:just_audio/just_audio.dart';
import 'dart:convert';

class MusicService {
  final String baseUrl = "https://<your-deployment>.vercel.app";
  final AudioPlayer _player = AudioPlayer();

  Future<List<dynamic>> search(String query) async {
    final res = await http.get(Uri.parse('$baseUrl/api/search?q=${Uri.encodeComponent(query)}'));
    final data = jsonDecode(res.body);
    return data['results'];
  }

  Future<void> playTrack(String videoId) async {
    final streamUrl = '$baseUrl/api/stream?id=$videoId';
    await _player.setUrl(streamUrl);
    _player.play();
  }
}
TypeScript / JavaScript (Fetch) 
const BASE_URL = "https://<your-deployment>.vercel.app";

async function searchAndPlay(query: string) {
  const searchRes = await fetch(`${BASE_URL}/api/search?q=${encodeURIComponent(query)}&limit=1`);
  const { results } = await searchRes.json();
  if (!results.length) return;

  const track = results[0];
  const audio = new Audio(`${BASE_URL}/api/stream?id=${track.id}`);
  await audio.play();

  const lyricsRes = await fetch(
    `${BASE_URL}/api/lyrics?title=${encodeURIComponent(track.title)}&artist=${encodeURIComponent(track.artists[0]?.name || '')}&duration=${track.durationSeconds}`
  );
  const lyricsData = await lyricsRes.json();
  return { track, lyrics: lyricsData };
}
